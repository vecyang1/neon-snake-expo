## [1.1.0] - 2026-05-22

### Added
- GitHub Pages automated deployment pipeline and asset base URL resolution.
- Responsive mobile viewport wrapper for web targets, preserving standard smartphone aspect ratio on desktop screens.

## [1.0.0] - 2026-05-21

### Added
- Complete cross-platform React Native + Expo port of the iOS Snake Game.
- **Neo-Noir & Cyberpunk Visual Style**:
  - High-contrast dark background with vibrant neon green/cyan snake segments and pulsing magenta food items.
  - Smooth animation loop with collision detection, directional swipe controls, and on-screen D-Pad.
  - Score tracking, high score persistence via AsyncStorage, and game-over overlay.
- EAS (Expo Application Services) build configuration for native iOS and Android bundles.
